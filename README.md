# Stream Deck 風アプリ（自作）

iPhone でアイコンをタップすると、**同じ Wi-Fi 内の Windows PC** で対応する操作（アプリ起動・URLを開く・キーボードショートカット・音量/メディア操作）を実行する、自作の Stream Deck 風アプリです。

既存アプリのサブスク前提・低いUI/UX（特にアイコン品質）への不満から、**無料・高品質なアイコン・自由なカスタマイズ**を目指して、アプリ開発の学習も兼ねて作っています。

## このプロジェクトの特徴
- 📱 **スマホ側は PWA**（Webアプリ）— Mac も App Store も不要、Windows だけで開発・公開できる
- 🖥️ **PC側は Node.js サーバー** — スマホと同じ JavaScript で書けて学習負荷が小さい
- 🔒 **LAN内のみ・許可リスト方式** — 設定ファイルに登録した操作だけを安全に実行
- 🎨 **高品質アイコン** — SVGアイコン＋カスタム画像で、どの画面でもぼやけない

## 想定アーキテクチャ（LAN内）
```
[iPhone: PWA] ──HTTP（同じWi-Fi）──> [Windows PC: Node.js サーバー]
                                         ├─ アプリ起動 / URLを開く（child_process / open）
                                         ├─ ショートカット送信（@nut-tree-fork/nut-js）
                                         └─ 音量・メディア操作（NirCmd / win-audio）
```

## 開発の進め方
アジャイルで「まず動くものを作る → 改善」を繰り返します。詳細なフェーズ分け（Phase 0〜5）と学習ロードマップは [要件定義書](docs/要件定義書.md) を参照してください。

- **Phase 0**：環境構築（Node.js / Git / VS Code、要件定義書）
- **Phase 1**：スマホのタップで PC のアプリを1つ起動（最初のゴール）
- **Phase 2**：4種のアクション＋設定ファイル（`buttons.json`）化
- **Phase 3**：UI刷新（Vite + React）＆ PWA化
- **Phase 4**：認証・HTTPS・常駐
- **Phase 5**：拡張（WebSocket・ドラッグ&ドロップ編集 など）

## 動作環境（前提）
- Windows PC（サーバー）＋ iPhone（クライアント）
- 両者が同じ Wi-Fi（LAN）に接続
