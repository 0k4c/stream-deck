# Phase 0：環境構築ガイド（Windows）

このガイドは、開発を始めるための「準備」を1ステップずつ行うものです。**あなたの Windows PC 上で**作業します（このリポジトリのコードを書く前段階）。

- **所要時間の目安**：30〜60分
- **このフェーズのゴール**：Node.js / Git / VS Code が入り、PCのIPアドレスが分かって固定され、リポジトリを手元に用意できている状態。
- 各ステップに **✅ 確認** があります。確認が通ってから次へ進みましょう。

> 困ったら：エラーメッセージをそのまま Claude に貼り付けて聞いてください。原因と直し方を一緒に探せます。

---

## 0. はじめに：用意するもの

- Windows PC（このアプリの「サーバー」になります）
- iPhone（「リモコン」になります）
- **同じ Wi-Fi**（PCとiPhoneが同じネットワークにつながっていること）

### ターミナルの開き方（Windows）
これから「コマンド」を打つ場面があります。ターミナル（黒い画面）は次のどれかで開けます。

- スタートボタンを右クリック →「**ターミナル**」または「**Windows PowerShell**」
- または、スタートメニューで「**PowerShell**」と検索して起動

> コマンドは「1行打って Enter」で実行します。コピペでOKです。

## 1. Node.js（PC側サーバーの土台）をインストール

「Node.js」は、PC上で JavaScript を動かす仕組みです。今回のサーバーをこれで作ります。

1. 公式サイト <https://nodejs.org/> を開く。
2. **「LTS」（推奨版）** のインストーラ（Windows Installer `.msi`）をダウンロード。
   - LTS = 長期サポート版。安定していて初心者向け。
3. ダウンロードした `.msi` を実行し、基本「Next」で進める。
4. **重要**：途中に「**Automatically install the necessary tools...（Tools for Native Modules）**」というチェックボックスが出たら **チェックを入れる**。
   - これは「あとでネイティブ部品をビルドする時に必要な道具（Python など）」を先に入れておくものです。今は使わなくても、入れておくと将来のエラーを防げます。
5. インストール完了後、**ターミナルを開き直して**次を実行：

```powershell
node -v
npm -v
```

> ✅ **確認**：`v20.x.x`（または `v22.x.x` 等）と `10.x.x` のようにバージョン番号が2つ表示されればOK。
> ❌ 「コマンドが見つかりません」と出たら、ターミナルを一度閉じて開き直す／PCを再起動してから再実行。

---

## 2. Git（変更を記録するツール）をインストール

「Git」は、コードの変更履歴を記録し、GitHub と同期するための道具です。

1. <https://git-scm.com/download/win> から「**64-bit Git for Windows Setup**」をダウンロード。
2. インストーラを実行。選択肢が多いですが、**基本はすべて初期設定（Next）でOK**。
3. インストール後、ターミナルで確認：

```powershell
git --version
```

4. 初回だけ、名前とメールを設定（GitHub に表示される署名です）：

```powershell
git config --global user.name "あなたの名前"
git config --global user.email "あなたのメール@example.com"
```

> ✅ **確認**：`git version 2.x.x` が表示されればOK。

---

## 3. VS Code（コードを書くエディタ）をインストール

「VS Code」は、コードを書くための高機能なメモ帳です。無料で、初心者にも人気です。

1. <https://code.visualstudio.com/> から Windows 版をダウンロードしてインストール。
2. 起動後、左側の拡張機能（四角が4つのアイコン）から、必要に応じて入れると便利：
   - **Japanese Language Pack**（メニューを日本語化）
   - **ESLint** / **Prettier**（コードを綺麗に保つ。Phase 1 以降で活躍）

> ✅ **確認**：VS Code が起動できればOK。

## 4. リポジトリ（このプロジェクト）を手元に用意する

GitHub 上のこのプロジェクトを、自分のPCにコピー（クローン）します。

1. ターミナルで、置きたい場所に移動（例：ドキュメント配下）：

```powershell
cd $HOME\Documents
```

2. クローン（`<リポジトリのURL>` は GitHub の「Code」ボタンから取得した HTTPS URL）：

```powershell
git clone <リポジトリのURL>
cd stream-deck
```

3. VS Code でこのフォルダを開く：

```powershell
code .
```

> ✅ **確認**：VS Code に `README.md` や `docs/` フォルダが見えればOK。
> 💡 すでにこのリポジトリで作業している場合（Web からのセッション等）は、`git pull` で最新を取得するだけでOKです。

## 5. PCのIPアドレスを調べる（スマホからアクセスするため）

iPhone から PC にアクセスするには、PCの「住所（IPアドレス）」が必要です。

1. ターミナルで実行：

```powershell
ipconfig
```

2. 「**ワイヤレス LAN アダプター Wi-Fi**」の項目にある「**IPv4 アドレス**」を探す。
   - 例：`192.168.1.42` のような番号。これがPCの住所です。**メモしておきましょう。**

> ✅ **確認**：`192.168.x.x` または `10.x.x.x` の形のIPv4アドレスが見つかればOK。

---

## 6. PCのIPアドレスを固定する（任意だが強く推奨）

IPアドレスは放っておくと**勝手に変わる**ことがあり（DHCP）、「昨日は繋がったのに今日は繋がらない」の原因になります。固定する方法は2つ：

- **方法A（おすすめ）：ルーターで「DHCP予約」**
  - ルーターの設定画面（例 `192.168.1.1` をブラウザで開く）→「DHCP予約 / 固定割り当て」で、PCのMACアドレスに対して常に同じIPを割り当てる。
  - ルーター側でやるので、PCの設定を壊しにくく安全。
- **方法B：Windows で固定IPを設定**
  - 設定 → ネットワークとインターネット → Wi-Fi → （接続中のネットワーク）→ IP割り当てを「手動」にして固定値を入力。
  - 値を間違えるとネットに繋がらなくなるので、自信がなければ方法Aを。

> ✅ **確認**：再起動してもPCのIPが変わらなければOK（後日 `ipconfig` で再確認）。
> 💡 難しければ今はスキップして、Phase 1 で繋がった後に戻ってきてもOKです。

---

## 7. Windows ファイアウォールについて（予告）

Phase 1 で初めてサーバーを起動すると、Windows が「**このアプリの一部の機能がブロックされました**」というダイアログを出します。

- その時は「**プライベートネットワーク**」にチェックを入れて「**アクセスを許可する**」を押してください。
- これで、同じ Wi-Fi 内（家のネットワーク）からのアクセスが通るようになります。
- 「パブリックネットワーク」にはチェックを入れない（外部に開かないため）。

> このステップは Phase 1 で実際に出てきます。今は「そういうものが出る」と知っておくだけでOK。

## 困ったとき（トラブルシューティング）

| 症状 | 原因・対処 |
| --- | --- |
| `node` / `git` が「見つかりません」 | インストール直後はターミナルを**開き直す**。直らなければPCを**再起動**。 |
| `ipconfig` でIPが2つ以上出る | 「Wi-Fi」アダプターの IPv4 を使う（「イーサネット」やVPNではなく、今つないでいるWi-Fiのもの）。 |
| IPが時々変わる | Step 6 の固定（DHCP予約）を行う。 |
| そもそも詰まった | エラー文をそのまま Claude に貼って質問。何をしようとして何が出たかを伝えると解決が早いです。 |
